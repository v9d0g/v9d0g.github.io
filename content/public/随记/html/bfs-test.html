现在做什么？
选择一个起点，然后点击“单步执行”。重点观察：BFS 为什么总是先处理距离起点更近的节点？
核心思想： BFS 使用 FIFO 队列。 节点第一次入队时就确定了它的最短无权距离；因此从同一个起点出发时， BFS 会按距离 0、1、2、3…… 的层次扩展。

③ 伪代码

BFS(start): queue ← empty queue visited[start] ← true distance[start] ← 0 enqueue(start) while queue is not empty: u ← dequeue() for each neighbor v of u: if v is not visited: visited[v] ← true distance[v] ← distance[u] + 1 parent[v] ← u enqueue(v)
