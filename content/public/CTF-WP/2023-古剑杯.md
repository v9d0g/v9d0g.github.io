### guess the key

`黑盾杯2019WEB原题——guess the key`http://www.manongjc.com/detail/18-azqewyhlwnbynee.html

题型:逆向解密

这个题应该是属于逆向的吧，难点是根据题目的C代码给出加密算法的逆向

```c
#include <stdlib.h>
#include <stdio.h>
#include <string.h>

int main(int argc, char **argv) {
	if (argc != 3) {
		printf("USAGE: %s INPUT OUTPUT\n", argv[0]);
		return 0;
	}
	FILE* input  = fopen(argv[1], "rb");
	FILE* output = fopen(argv[2], "wb");
	if (!input || !output) {
		printf("Error\n");
		return 0;
	}
	char key[] = "guessthekey";
	char d, q, t = 0;
	int ijk = 0;
	while ((q = fgetc(input)) != EOF) {
		d = (q + (key[ijk % strlen( key )] ^ t) + ijk*ijk) & 0xff;
		t = q;
        ijk++;
		fputc(d, output);
	}
	return 0;
}
```

根据加密算法写出逆向的解密算法

```python
def _l_inv(idx, s):
    return s[-idx:] + s[:-idx]

def decrypt(c, k1, k2):
    s = "ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789abcdefghijklmnopqrstuvwxyz_{}"
    t = [[_l_inv((i+j) % len(s), s) for j in range(len(s))] for i in range(len(s))]
    decrypted_text = ""
    i1 = 0
    i2 = 0
    for char in c:
        decrypted_char = t[s.find(k1[i1])][s.find(k2[i2])].index(char)
        decrypted_text += s[decrypted_char]
        i1 = (i1 + 1) % len(k1)
        i2 = (i2 + 1) % len(k2)
    return decrypted_text
```

在`key`与明文长度已知的情况下，可以通过爆破或者猜具体的密钥来得到明文

### I have the flag

`黑盾杯2019WEB原题——i have the_flag`http://www.manongjc.com/detail/18-azqewyhlwnbynee.html

题型:代码审计

主要是js代码的加密规则，前端是要输入正确的`TOKEN`才能返回`FLAG`

但是js源码里面只有一堆加密逻辑，唯一可以用的貌似只有这个函数

```js
function ck(s) {
    try {
        ic
    } catch (e) {
        return;
    }
    var a = [118, 108, 112, 115, 111, 104, 104, 103, 120, 52, 53, 54];
    if (s.length == a.length) {
        for (i = 0; i < s.length; i++) {
            if (a[i] - s.charCodeAt(i) != 3)
                return ic = false;
        }
        return ic = true;
    }
    return ic = false;
}
```
