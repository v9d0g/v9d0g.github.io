# 2021-第五届世界智能大会

## hate-php

题型:RCE

漏洞原因:eval($code);

```php+HTML
 <?php
error_reporting(0);
if(!isset($_GET['code'])){
    highlight_file(__FILE__);
}else{
    $code = $_GET['code'];
    if(preg_match("/[A-Za-z0-9_$@]+/",$code)){
        die('fighting!'); 
    }
    eval($code);
} 
```

过滤了大小写字母、数字、下划线、$、@

数字被过滤=>异或绕过不可行

$被过滤=>自增绕过不可行

`eval()`函数是代码执行 并不像`system()`一样直接执行命令

同时 反引号`包含的内容可以直接识别成命令

```php+HTML
<?php echo `ls` ?>
=>
system('ls')
```

------

除此之外 在Linux系统中，是支持正则的，某些你忘记某个字符情况下，你可以使用`? * %`等字符来替代

```php+HTML
cat /bin/var/www/html
=>
cat /???/???/???/????
```



```dd
linux/unix文件系统结构
    /：根目录，整个文件系统的顶级目录。
    /bin/：存放系统命令和可执行程序，例如 ls、cp、mv 等。
    /boot/：存放启动相关文件，例如内核文件和启动引导程序。
    /dev/：设备目录，存放设备文件，例如硬盘、键盘、鼠标等设备的节点文件。
    /etc/：存放系统配置文件，例如用户账户信息、网络配置、服务配置等。
    /home/：用户主目录，每个用户的个人文件和配置存放在各自的子目录中。
    /lib/：存放系统库文件，包括共享库和内核模块。
    /media/：挂载点目录，用于挂载可移动媒体设备，如光盘、USB 等。
    /mnt/：挂载点目录，用于临时挂载其他文件系统。
    /opt/：存放可选软件包的安装目录，通常由第三方软件安装在此目录下。
    /proc/：虚拟文件系统目录，用于存放内核和进程信息。
    /root/：超级用户（root）的主目录。
    /run/：运行时数据目录，存放系统运行时的临时文件。
    /sbin/：存放系统管理员命令，通常只有超级用户才能执行。
    /srv/：存放服务数据目录，用于存放特定服务的数据。
    /tmp/：临时目录，用于存放临时文件，该目录下的文件在系统重启时会被清空。
    /usr/：存放用户安装的应用程序和文件，是一个较大的目录，包含了许多子目录。
    /var/：存放变化数据，例如日志文件、数据库文件、邮件等。
```
